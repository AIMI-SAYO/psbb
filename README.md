# PSBB

Faster console downloads, by AimiSayo.

PSBB is a free Windows app that speeds up PS5, PS4 and PS3 game downloads by fetching them over many connections through your PC. It can also save a whole game on a PC, at home or anywhere, for the console to install later at full home-network speed.

- Website: https://psbb.aimisayo.com
- Download: [latest release](https://github.com/AIMI-SAYO/psbb/releases/latest)
- Game list: https://psbb.aimisayo.com/games.html

This repository holds the website, the public game list (`docs/games.json`, refreshed automatically) and the release downloads. The source code is not public.
